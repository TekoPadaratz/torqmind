# Pacote de Agents TorqMind para VS Code

Este pacote cria os agents e prompts do TorqMind.

## Instalar no repo

```bash
unzip torqmind-vscode-agents-pack.zip -d .
git status -sb
```

## Ver no VS Code

1. Abra o repositório TorqMind no VS Code.
2. Abra o Chat do Copilot.
3. Clique no seletor de Agents.
4. Procure `TorqMind Código`, `TorqMind SSH Produção`, `TorqMind Git Release`.
5. Se não aparecer, rode `Chat: Open Customizations` no Command Palette e veja a aba Agents.

## Usar prompt files

Digite `/` no Chat ou use Command Palette:
- `/debug-producao`
- `/deploy-producao`
- `/auditar-zip`
- `/validar-marts-clickhouse`
- `/validar-controle-acesso`
